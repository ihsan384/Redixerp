# Rediz ERP

Rediz ERP is a comprehensive business management system built with modern web technologies. It provides robust solutions for inventory management, customer relationship management, accounting, and overall business operations.

## Features

- **Inventory Management**: Track stock levels, manage products, and control inventory with ease.
- **Customer Relationship Management (CRM)**: Manage customer data, interactions, and relationships.
- **Accounting**: Handle financial transactions, ledgers, and financial reporting.
- **Sales & Invoicing**: Create and manage sales orders, invoices, and billing.
- **Purchase Management**: Streamline procurement processes and vendor management.
- **User Management**: Secure authentication and role-based access control.
- **Dashboard**: Real-time insights and analytics for business performance.

## Tech Stack

- **Frontend**: React.js
- **Styling**: Tailwind CSS, Shadcn UI Components
- **State Management**: Redux Toolkit
- **Routing**: React Router DOM
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Form Handling**: React Hook Form, Zod

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd redixerp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

## Usage

- The application runs on `http://localhost:5173` by default.
- Use the navigation menu to access different modules: Dashboard, Inventory, Customers, Sales, Purchases, and Settings.
